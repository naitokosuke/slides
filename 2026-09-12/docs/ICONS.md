# アイコンの出典

`src/public/icons/` の PNG は [zhaotianff/Win98-Icons](https://github.com/zhaotianff/Win98-Icons) から取得した Windows 98 のシステムアイコンです。ファイル名は上流のまま置いています。

`PixelIcon.vue` のマッピング。

| `name`   | ファイル                  | 元アイコン        |
| -------- | ------------------------- | ----------------- |
| `folder` | `directory_closed-4.png`  | フォルダ          |
| `drive`  | `hard_disk_drive-4.png`   | ハードディスク    |
| `trash`  | `recycle_bin_full-4.png`  | ごみ箱 (中身あり) |
| `chip`   | `chip_ramdrive-4.png`     | RAM ドライブ      |
| `mirror` | `monitor_blue_grad-0.png` | モニタ            |

リポジトリ側のライセンス表記は MIT ですが、アイコンの図案そのものは Microsoft が Windows 98 のために制作したものです。MIT はリポジトリの著作者が付与できる範囲にしか及びません。このデッキは 98.css で Windows 98 の UI を再現した個人発表用のパスティーシュとして使っています。
